# Ruang Integrasi Pengenalan Wajah

Folder ini disediakan sebagai ruang kerja untuk mengembangkan dan mengintegrasikan
fitur pengenalan wajah dengan backend LookIn.

Saat ini belum ada kode layanan pengenalan wajah yang aktif. Sebelum menghubungkan
fitur ini ke aplikasi, sepakati terlebih dahulu kontrak API dan alur presensi dengan
tim utama. Simpan kode, daftar dependensi, dan dokumentasi layanan di folder ini.

Jangan commit virtual environment (`.venv`), model hasil unduhan, atau data wajah.
Tambahkan instruksi setup dan cara menjalankan tes saat layanan mulai dibuat.
